# Timetable Portal

Author: Kosimova Ranokhon  
Course: Web Programming  

## Project Description

Timetable Portal is a web application for managing university schedules.

The system supports:
- User authentication (login system)
- Admin panel for creating timetable entries
- Read-only timetable view for students
- MySQL database integration
- Session-based authorization

## Technologies Used

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js
- MySQL

## Features

- Role-based access (Admin / Student)
- Create timetable entries (admin only)
- View timetable (all users)
- Database validation
- REST API structure

## Database Structure

Main tables:
- users
- subjects
- rooms
- timetable

## How to Run

1. Install dependencies:
   npm install

2. Start server:
   node server.js

3. Open in browser:
   http://localhost:3000
